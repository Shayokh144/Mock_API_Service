How this works
  • Rules are kept. Deleting history does not delete rules.
  • URL contains matches the path and query, ignoring case. Apply stores it in the address. Typing filters the rows. Reload the page if JavaScript is off.
  • Group similar requests is on unless the address has group=0. A group is the same method, the same upstream, and the same path. The query string is ignored. The arrow opens the group. Without JavaScript it is a link, and open in the address keeps it open.
  • A fresh-request rule is a real server response. Its source stays upstream, so Real server includes it. The source column says upstream (fresh rule). It is not a mock. upstream-error and rejected stay under All.
