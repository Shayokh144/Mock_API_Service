Fresh request forwards this match to your upstream server (develop/staging) and strips cache validators so the upstream can return a full body. The upstream server must be reachable. The saved status and body are not used while this is checked.

Any upstream matches every request. A named upstream matches only when the request resolves to that upstream, by its prefix or as the fallback.

Use an exact path, or * for one whole segment. Example: /api/users/*. The query string is not part of the pattern, so do not include ?.

Optional. One condition per line. refresh_token means that query key is present. page=2 means that exact value. Every line must match.

Optional. One condition per line, for a form body or a JSON body. grant_type=refresh_token matches a form field. user.role=admin matches a JSON path. Numbers and booleans match their text, so active=true matches true. A body over 1 MiB does not match. Every line must match.

Optional. Wait this many milliseconds before the response is written. Use it to try loading states, spinners, and client timeouts. 0 means no wait. The maximum is 60000.

Response mode

Fields builds the response from a status, headers, and JSON body. Raw response sends the pasted HTTP response instead. Fresh request still forwards to the upstream and ignores both.

Paste a status line, headers, a blank line, and the body. CRLF and LF both work. Content-Length is recomputed. Do not set Transfer-Encoding.

Raw responses omit this header unless you check it. Fields mode always adds it.

One header per line, as Name: value. Used in Fields mode.

Leave the body empty for no response body. Used in Fields mode.
